# Product-name clearance screen — Lantern

Date: 2026-07-27  
Decision: **Do not adopt `Lantern` as the final standalone product name. Retain it only
as an internal project codename while a distinctive replacement is cleared.**

This is a practical preliminary screen, not a legal opinion or comprehensive trademark
search.

## Material conflicts and crowding

- Apple currently lists **Lantern – Floating Web Search**, a productivity application for
  macOS. This creates a direct marketplace-name collision for the intended Mac distribution:
  <https://apps.apple.com/us/app/lantern-floating-web-search/id6747213574>
- `lantern.ai` is an active AI-powered private-markets data platform:
  <https://www.lantern.ai/>
- `lantern.dev` is an active AI application/Postgres software company:
  <https://lantern.dev/about>
- `asklantern.com`, `withlantern.com`, and `lantern.is` are active AI/software products:
  <https://www.asklantern.com/about>
  <https://withlantern.com/>
  <https://lantern.is/>
- Historical US software trademark activity exists for the standard word `LANTERN`,
  including broad software descriptions. The located record is marked abandoned, but it
  demonstrates a crowded software field rather than availability:
  <https://uspto.report/TM/76343161>

## Product risk

Even if a narrow registration were legally possible, the name would have weak search
distinctiveness, confusing app-store results, crowded domains, and likely higher trademark
clearance and marketing costs. Adding a descriptive suffix such as `Notes`, `AI`, or
`Knowledge` would not necessarily remove the dominant shared term or marketplace confusion.

## Repository decision

- Existing `Lantern` names remain unchanged because they identify the current internal
  development project and artifacts.
- No stable version, public store identity, signing identity, domain, or trademark filing
  should be created under standalone `Lantern`.
- Final renaming should occur once, before `1.0.0`, signing, store reservation, public URLs,
  and user-data directory stability commitments.

## Required clearance for a replacement

1. Generate distinctive coined candidates rather than common dictionary/software terms.
2. Search USPTO TESS/TSDR, WIPO Global Brand Database, relevant state/business registries,
   Apple/Microsoft/Google stores, package managers, GitHub, and general web usage.
3. Check exact and confusingly similar domains and social identifiers.
4. Have qualified trademark counsel perform a comprehensive search in intended markets.
5. Reserve the approved domains, package identifiers, and store names before repository-wide
   renaming.
