# Product-name screen — Sky Writer

Date: 2026-07-27  
Decision: **Do not use `Sky Writer` or `Skywriter` as the product name.**

This is a preliminary availability screen, not a comprehensive legal opinion.

## Conflicts

- `SkyWriter.ai` is an active ChatGPT-based content and image generation product:
  <https://www.skywriter.ai/faq>
- `Skywriter.dev` is an active self-hosted HTML/Markdown publishing and editing platform:
  <https://skywriter.dev/>
- `Skywriter.com` describes an established cloud content-management and distribution product:
  <https://www.skywriter.com/instructors/>
- Steam distributes a Windows game named `Skywriter`:
  <https://store.steampowered.com/app/919040/Skywriter/>
- Mozilla previously used `Skywriter` for its browser-based code editor.
- `SkyWriter Software` appears as the named developer/copyright holder for current Apple
  applications.

The collisions include AI content generation, Markdown/content management, editing software,
and Windows software. Spacing the words does not create a meaningfully distinct dominant name.

## Preliminary alternative shortlist

These candidates need formal trademark, company-registry, domain, and international
clearance before adoption:

1. **Nimvara** — strongest preliminary candidate. Exact searches found no software, app-store,
   GitHub, or readily indexed trademark collision.
2. **Orbynote** — no exact indexed software collision found; descriptive `note` suffix makes
   the mark weaker and should be counsel-reviewed.
3. **Orivell** — no direct software collision found, but an active unrelated US household-goods
   trademark application and similar health-product usage exist.

Rejected during this screen:

- **Vellumark** — existing Markdown/knowledge-management App Store product.
- **Cairnly** — multiple active AI, CRM, finance, and career products.
- **LumenFold** — existing productivity app and other software/project use.
- **Avenquill** — active Android browser and company name.
- **Veylume** — active commerce and music brand.

## Recommendation

Advance **Nimvara** to a proper legal clearance search. Do not rename binaries, user-data
folders, application identifiers, or signing identities until that search and domain/store
reservation are complete.
