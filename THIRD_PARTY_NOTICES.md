# Third-party notices

Nimvara includes open-source Rust and Tauri dependencies. The authoritative dependency inventory for each build is the release's CycloneDX SBOM (`lantern.cdx.json`) generated from the locked dependency graph.

Redistribution must include all notices and license texts required by those dependencies. This file is not a substitute for the final automated license-policy report. Public release is blocked until that report confirms that every bundled dependency and model is compatible with Nimvara's selected product license and distribution channels.

No AI model is bundled in the current package.
