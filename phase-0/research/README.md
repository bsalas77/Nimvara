# Phase 0 research repository

This directory is the private-ready research repository described in [the user research plan](../../05-user-research-plan.md). It currently contains templates and secondary-research records only. No participant interviews, usability sessions, or measured benchmarks have occurred.

## Repository contents

- [Evidence register](evidence-register.md) — sources, claims, strength, and gaps
- [Request evidence register](request-evidence-register.md) — user requests mapped to requirements
- [Interview and usability kit](interview-and-usability-kit.md) — consent-safe guide, note template, and scorecard

## Evidence states

| State | Meaning |
|---|---|
| `source-reviewed` | A cited document or public source was reviewed |
| `user-request` | Direct instruction from the project owner |
| `hypothesis` | Plausible but not yet validated |
| `planned` | Research or test is designed but not run |
| `observed` | Behavior was directly observed and recorded |
| `measured` | A repeatable test produced recorded results |
| `decision` | Project decision, with rationale and owner |

Only `observed` and `measured` records can satisfy behavioral or performance gates.

## Privacy and handling

- Assign participants anonymous IDs such as `P01`.
- Store consent status, not signatures or contact information, in this project.
- Do not paste private note content; record behavior and sanitized examples.
- Keep recordings outside the application repository in an access-controlled location.
- Record deletions or retention deadlines for any research media.
